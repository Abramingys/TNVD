# Источники номенклатуры

[Решение Совета ЕЭК № 80](https://docs.eaeunion.org/documents/386/6099/) содержит базовое утверждение и приложение в Word. Для актуального среза требуется сверка вступивших в силу изменений.

[Сводная страница ЕЭК](https://eec.eaeunion.org/comission/department/catr/ett/) публикует перечень учтённых изменений, разделы и ссылки на PDF групп. В [PDF группы 09](https://eec.eaeunion.org/upload/files/catr/ett/ru.09_2022_25.04.2022.pdf) бескодовые узлы определяются уровнем отступа, а таблица переносится между страницами. Используйте сводный каталог для проверки покрытия и сверяйте даты вступления изменений в силу по правовому порталу.

[Решение Коллегии ЕЭК № 126](https://docs.eaeunion.org/upload/iblock/4dd/4lwbdmh6pjnws7jgh7fnk07twmtunhzp/err_24082023_126_doc.pdf) описывает форматы XML для позиций и примечаний. [Реестр НСИ ЕАЭС](https://nsi.eaeunion.org/portal/info) — кандидат на получение выгрузки.

Полный актуальный файл, действующие даты, полнота примечаний и условия коммерческого использования пока не подтверждены. Сверяйте редакцию, охват разделов, итоговое число позиций и контрольные строки с официальным источником. Национальные документы Беларуси и России в базе пока отсутствуют.
