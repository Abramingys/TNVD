# Импорт ТН ВЭД

Импортёр принимает нормализованный UTF-8 JSON. Корень содержит `version`, `effectiveFrom`, опциональный `effectiveTo`, HTTPS-ссылку `source` и массив `rows`. В строке указываются `key`, `parent` (ключ или null), `code` (строка или null), `title`, `leaf`. Дополнительные поля — `notes`, `validFrom`, `validTo` и `source`. Сохраняйте исходный порядок строк.

Для подготовки из PDF выполните `scripts/download-eec.ps1`. Скрипт сохраняет документы по группам и их SHA-256 в `.tnved-source/manifest.json`. Затем запустите `python scripts/extract-eec-tables.py .tnved-source --output .tnved-source/extracted-review.json` в окружении с PyMuPDF. Это вспомогательный скрипт подготовки данных, который извлекает строки с номерами страниц для сверки.

Выгрузка с пометкой `review_required` требует сверки с PDF. Проверьте полноту, продолжения таблиц, переносы строк, бескодовые уровни и примечания. После сверки преобразуйте её в формат нормализованного снимка, добавив явные связи родителей, даты редакции и ссылки на источники.

```powershell
npm run import:tnved -- snapshot.json --dry-run
```

Для загрузки задайте в окружении процесса `NEXT_PUBLIC_SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY`. Без флага `--activate` скрипт загружает черновик. Повтор с тем же SHA-256 продолжает загрузку без дубликатов.

После независимой проверки полноты и актуальности задайте `TNVED_APPROVED_SHA256` из отчёта dry run и выполните запуск с `--activate`. Чтобы вернуться к предыдущей редакции, пока она действует, повторите активацию её проверенного файла.
