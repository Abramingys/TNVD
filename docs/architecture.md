# Архитектура

Next.js обслуживает страницы, API и серверные действия. Клиентские компоненты отвечают за поиск с задержкой и отменой запросов, дерево и элементы управления. Supabase Auth хранит сеанс в cookies, которые обновляет Next.js proxy. Серверная функция `searchTnvedCodes` объединяет вызовы Postgres RPC и демо-поиск.
